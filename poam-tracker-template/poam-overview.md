# POA&M Overview

## Purpose
A Plan of Action and Milestones (POA&M) is used to document identified weaknesses, define corrective actions, assign responsibility, and track remediation progress over time.

## Role in Security Documentation
A POA&M supports risk management by showing that known issues are not ignored. Instead, they are documented, prioritized, assigned to an owner, and tracked through planned milestones until closure or risk acceptance.

## Typical Elements
A POA&M entry often includes:
- Weakness description
- Related control
- Risk or severity level
- Planned remediation actions
- Responsible owner
- Target completion date
- Milestone updates
- Current status

## Portfolio Purpose
This project uses a mock POA&M tracker to demonstrate how corrective action documentation may be structured in an RMF-aligned environment.
