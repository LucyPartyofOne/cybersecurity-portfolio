# POA&M Tracker Template

## Overview
This project is a mock Plan of Action and Milestones (POA&M) tracker created for portfolio purposes. It demonstrates how security weaknesses can be documented, assigned, prioritized, and tracked through remediation in a structured and audit-ready format.

## Purpose
The purpose of this project is to show practical understanding of how a POA&M supports risk management, corrective action tracking, and ongoing security documentation within an RMF-aligned environment.

## Included Work
- `poam-overview.md` — explanation of the purpose and structure of the tracker
- `poam-tracker.md` — sample POA&M entries with owners, milestones, and status
- `remediation-workflow.md` — example workflow for reviewing and updating POA&M items

## Scenario
This sample project assumes a fictional information system with documented control gaps identified during review activities. The tracker demonstrates how findings may be documented and followed through closure.

## Note
This project is a demonstration artifact for learning and portfolio use only. It does not represent a real system, real weaknesses, or an official authorization package.
