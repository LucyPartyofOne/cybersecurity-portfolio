# Monitoring Overview

## Purpose
Continuous monitoring helps maintain ongoing awareness of system security posture, control effectiveness, open findings, and relevant changes that may affect risk.

## Role in RMF-Aligned Work
In an RMF-aligned environment, monitoring is not a one-time activity. It supports ongoing review of implemented controls, documentation updates, remediation follow-up, and reporting to help decision-makers understand current security status.

## Monitoring Objectives
The objectives of continuous monitoring typically include:
- Maintaining visibility into control status
- Identifying new weaknesses or changes
- Tracking remediation progress
- Supporting reporting and escalation
- Keeping documentation current
