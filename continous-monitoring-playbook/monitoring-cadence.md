# Monitoring Cadence

## Purpose
This document provides a sample schedule for recurring monitoring activities in an RMF-aligned environment.

## Monthly Activities
- Review open POA&M items and remediation updates
- Review access changes and account management activity
- Review logging summaries and notable events
- Confirm documentation updates for recent system changes

## Quarterly Activities
- Review control implementation status
- Reassess recurring findings or trends
- Review evidence references for completeness
- Validate that key procedures remain current

## Annual Activities
- Review core security documentation for accuracy
- Reassess monitoring strategy and reporting needs
- Review roles and responsibilities for control ownership
- Confirm that major procedures and governance documents remain aligned

## Event-Driven Activities
- Reassess documentation after significant system changes
- Review findings after incidents or notable control failures
- Update trackers and reports when new weaknesses are identified
- Escalate issues requiring corrective action or leadership review

## Notes
This cadence is a simplified example created for portfolio purposes. In practice, monitoring frequencies are often adjusted based on system risk, control criticality, and organizational requirements.
